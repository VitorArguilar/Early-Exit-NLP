# Backup dos resultados anteriores

Este diretório reúne os artefatos que estavam no repositório antes da rodada com early stopping de até 100 épocas:

- `outputs/`: métricas e checkpoints dos experimentos anteriores, incluindo a exploração de 30 épocas e as avaliações de Early Exit.
- `final/`: tabelas, gráficos e scripts de consolidação anteriores.
- `apresentação/`: figuras e tabelas preparadas para a apresentação anterior.

O novo protocolo e seus resultados estão em [`../ESTUDO_100_EPOCAS.md`](../ESTUDO_100_EPOCAS.md) e [`../outputs/100epochs/`](../outputs/100epochs/). Os arquivos deste backup não foram usados para iniciar os novos modelos base.
